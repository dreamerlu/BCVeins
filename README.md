# BCVeins
A modified Veins that support blockchain simulation based on Veins V5.2
# 2024年7月18日：
今天将代码仓库设置为public，现尝试在安徽大学车联网课题组内使用。
PS：车联网课题组对区块链感兴趣的同学可以关注BCVeins（支持区块链的veins），目前我已将其放到GitHub的公共仓库里。BCVeins是为了解决目前车联网仿真平台不支持区块链系统的问题，因此我从去年年底在有空时基于veins5.2（开源车联网仿真框架）写出了一些基本模块。现版本是在与曹远志合作开展研究时产生的改进版本，在他做实验时大量测试后发现了其中不少bug后，进行了修复，目前大部分bug已经修复，并且实现了批量测试功能（之前版本开展大规模测试需要点击无数次，耗时非常久。。。），在进行大规模测试时能够极大地减少无聊的测试时间。当前版本只支持PoW共识机制，实现多RSU间的区块同步。后续我们希望能够支持更多的共识机制，包括BFT、PoS等等。欢迎有兴趣的同学加入进来发展、改进它，也欢迎大家使用它、提出改进建议、贡献技术文档！
# 2024年7月8日：
实现了一个Block能够容纳多个事务，类似于比特币对区块容量进行限制从而间接限制能够容纳的事务数量；修复了一些bug；并且实现了批量运行demo。
